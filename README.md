# Team18 Nginx Controller (Go)

## Description
This project is built with Go (Golang) and provides functionality to manage or control Nginx configurations.

---

## Tech Stack
- Go (Golang)
- Nginx
- Docker (optional)

---

## Requirements

Before running this project, make sure you have:

### 1. Install Go
Download from:
```
sudo apt update
sudo apt install golang-go
```

Verify installation:
```bash
go version


### 2. Install Nginx
```
apt update
apt install nginx -y
```
